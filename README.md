# AUTOCAT loader

ตัวโหลดสำหรับลูกค้า มีการตรวจคีย์และผูกเครื่องก่อนเริ่มสคริปต์

**สถานะ: รอตั้ง HTTPS URL ของเซิร์ฟเวอร์ตรวจคีย์ ยังไม่พร้อมแจกใช้งาน**

## เปิดใช้งาน

เมื่อผู้ดูแลตั้งเซิร์ฟเวอร์แล้ว ลูกค้าใช้ `/redeem` ใน Discord เพื่อรับสิทธิ์ก่อน แล้วรัน:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/worawutsecond-ship-it/autocat/main/loader.luau"))()
```

กรอกคีย์แล้วกด Activate เครื่องเดิมจำสิทธิ์จนคีย์หมดอายุ หนึ่งคีย์ผูกได้หนึ่งเครื่อง ถ้าย้ายเครื่องให้ผู้ดูแลรีเซ็ตก่อน การผูกเครื่องขึ้นกับตัวระบุที่ client ส่งและไม่ใช่การป้องกันการคัดลอกที่รับประกันได้

ถ้าตัวรันแจ้งให้ติดตั้งข้อมูลเครื่อง ให้ดาวน์โหลด [Install-Client.ps1](https://raw.githubusercontent.com/worawutsecond-ship-it/autocat/main/Install-Client.ps1) แล้วรันบนคอมลูกค้า จากนั้นเปิด `RIVALS-License-Loader.luau` ใน workspace ของ Real

## สำหรับผู้ดูแล

ตั้ง `licenseServer` ใน `config.json` เป็น HTTPS origin สาธารณะ เช่น `https://license.example.com` โดยไม่มี `/` ท้าย URL แล้วตั้ง `PUBLIC_BASE_URL` ฝั่งระบบคีย์ให้เป็น URL เดียวกันและรีสตาร์ต API กับบอท

ห้ามใส่ `127.0.0.1` หรือ `localhost` ใน config ที่แจกให้ลูกค้า GitHub แจกไฟล์ตัวโหลด ส่วนระบบตรวจคีย์และฐานข้อมูลต้องเปิดอยู่บนคอมผู้ดูแลหรือ VPS ถ้ารันบนคอมผู้ดูแลต้องเปิดคอมและเซิร์ฟเวอร์ไว้ขณะใช้งาน

เมื่อ HTTPS URL ผ่านการทดสอบแล้ว ให้ปรับบรรทัดสถานะด้านบนเพื่อแจ้งพร้อมใช้

Repo นี้มีเฉพาะตัวโหลดและการตั้งค่า URL ไม่เก็บ `.env`, token บอท, คีย์, fingerprint, ฐานข้อมูลลูกค้า หรือสคริปต์หลักที่ไม่ตรวจคีย์ ห้ามอัปโหลดชุด VPS ทั้ง ZIP ลง repo สาธารณะ
